Using Transformation
-------------------
Let's work on hadoop log data 

Using stats function
index=hadooplogs | stats count(typeofmsg) by host
index=hadooplogs | stats count(typeofmsg)  BY date_second
index=hadooplogs | stats count(typeofmsg) as count_of_msgs BY date_second | sort count_of_msgs

Also click on visualization > column chart 

==========================
Using top
index=hadooplogs sourcetype="*" | top limit=20 typeofmsg

Verbose mode : events > 96
Statistics : shows typeofmsgs, count and percent in a tabular format
Visualizations : show 'typeofmsg' and count

Similarly Using rare
index=hadooplogs sourcetype="*" | rare limit=20 typeofmsg
