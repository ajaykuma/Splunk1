#Using CommandLine and ParentCommandLine
These are fields associated with Sysmon process creation events, particularly EventCode 1 (Process Create)
A user executes a suspicious executable called 3791.exe
Parent process: cmd.exe
(The process that launches another process)

Child process: 3791.exe (The newly created process)

Field			Example value
Image			C:\Temp\3791.exe
CommandLine		"C:\Temp\3791.exe" -connect server
ParentImage		C:\Windows\System32\cmd.exe
ParentCommandLine	cmd.exe /c C:\Temp\3791.exe

CommandLine: The complete command used to start the current process, including its executable path and arguments.
ParentCommandLine: The command used to start the parent process (the process that launched the current process).

See which fields contain 3791.exe>
index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe"
| table _time EventCode Image CommandLine ParentImage ParentCommandLine
<shows 69 events>

Check whether CommandLine exists>
index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe"
| where isnotnull(CommandLine)
| table _time EventCode Image CommandLine

Check whether ParentCommandLine exists>
index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe"
| where isnotnull(ParentCommandLine)
| table _time EventCode CommandLine ParentCommandLine

Search for 3791.exe anywhere within CommandLine>
index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe"
| where like(CommandLine, "%3791.exe%")
| table _time EventCode CommandLine ParentCommandLine

With regex
index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe"
| rex field=_raw "<EventID>(?<EventCode>\d+)</EventID>"
| rex field=_raw "<Data Name='CommandLine'>(?<CommandLine>[^<]*)</Data>"
| rex field=_raw "<Data Name='ParentCommandLine'>(?<ParentCommandLine>[^<]*)</Data>"
| rex field=_raw "<Data Name='Image'>(?<Image>[^<]*)</Data>"
| rex field=_raw "<Data Name='ParentImage'>(?<ParentImage>[^<]*)</Data>"
| table _time EventCode Image CommandLine ParentImage ParentCommandLine

or

index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe"
| rex field=_raw "<EventID>(?<EventCode>\d+)</EventID>"
| rex field=_raw "<Data Name='CommandLine'>(?<CommandLine>[^<]*)</Data>"
| rex field=_raw "<Data Name='ParentCommandLine'>(?<ParentCommandLine>[^<]*)</Data>"
| search EventCode=1
| table _time EventCode CommandLine ParentCommandLine

Note**
_raw	Original event data, including XML
Field extraction	Converts XML elements into searchable fields
rex	Extracts fields using regular expressions at search time

<May not work>
index=botsv1 source="WinEventLog:Microsoft-Windows-Sysmon/Operational" "3791.exe" CommandLine="3791.exe" 
ParentCommandLine="*" | table _time SystemTime CommandLine ParentCommandLine EventCode Hashes
Because:
It relies on Splunk automatically extracting these fields:
- CommandLine
- ParentCommandLine
- EventCode
- Hashes
- SystemTime

In our current installation, the XML is visible in _raw, but those fields are not necessarily extracted.
Different Splunk versions or default configurations.
Different Windows Add-on versions.
Different sourcetype configurations.
Different XML field extraction settings.
